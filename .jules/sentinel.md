## 2026-07-12 - Hardening Unauthenticated Edge Functions
**Vulnerability:** Edge Functions such as the sms and uber routes were completely unauthenticated, meaning anyone could call them directly if they found the URLs, potentially draining third-party API credits (Africa's Talking SMS/Uber Direct) or causing unauthorized actions.
**Learning:** By default, Supabase Edge Functions do not enforce JWT validation on incoming HTTP requests unless explicitly coded. Developers assume that because functions are hosted in Supabase, they are secured behind client keys or auth, but standard requests can bypass this if authentication checks are missing in the Deno code.
**Prevention:** Always verify the presence of the `Authorization` header, parse the Bearer JWT case-insensitively and cleanly (trimming whitespace/handling variations), and validate the token via `supabaseClient.auth.getUser(token)` before proceeding with sensitive or credit-consuming third-party operations. Return clear 401/403 or generic 500 responses without leaking internal stack traces.
