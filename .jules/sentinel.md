## 2026-07-12 - Price Manipulation and Unauthorized Triggers in Edge Functions
**Vulnerability:** The M-Pesa STK Push Edge Function (`supabase/functions/mpesa/index.ts`) accepted payment amount and order parameters directly from the client request body without requiring authentication or verifying order ownership. This allowed malicious actors to trigger unauthorized STK Push prompts and manipulate payment amounts (e.g. paying 1 KES for high-value orders).
**Learning:** Client-facing payment endpoints must never trust client-supplied monetary values or IDs. In Supabase Edge Functions, requests must authenticate the user via JWT (`supabase.auth.getUser()`) and look up transaction totals directly from the database using a service role client to bypass user RLS and verify that the caller is indeed the authorized buyer.
**Prevention:** Always enforce JWT verification on financial endpoints, retrieve prices directly from database records, validate order status (e.g. status must be 'pending'), and return sanitized, generic error responses without exposing internal error details.
