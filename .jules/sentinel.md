## 2026-07-12 - Missing Authenticated Invocation on SMS Edge Function
**Vulnerability:** The SMS Deno Edge Function (`supabase/functions/sms/index.ts`) was entirely unauthenticated and allowed arbitrary invocation without validating the caller's identity or token. Any external client could send requests with random receiver phone numbers and message content, which would be processed via Africa's Talking API, leading to potential financial drain (billing abuse) and spam vectors.
**Learning:** Deno Edge Functions in Supabase do not automatically enforce authentication by default. Developers must explicitly extract the `Authorization` header, parse and trim the Bearer token, and verify it via `supabase.auth.getUser(token)` to authorize the request safely.
**Prevention:** Always verify the caller's JWT token within each Edge Function's handler and validate that the required request body parameters match strict schema types (e.g., checking that parameter fields are non-empty strings). Ensure errors do not leak internal stack traces to callers by wrapping everything in safe try-catch blocks returning generic error messages.
