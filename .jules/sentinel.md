## 2026-07-12 - M-Pesa STK Push Payment Tampering and Missing Edge Function Authorization
**Vulnerability:** The `mpesa` Supabase Edge Function accepted arbitrary `amount` parameters directly from untrusted client requests without verifying caller authentication or ensuring the amount matched the order in the database. Furthermore, internal error stack details were returned to the client on failure.
**Learning:** Edge Functions invoked via client-side SDKs (`supabase.functions.invoke`) pass the caller's JWT in the `Authorization` header, but Edge Functions running under Deno serve endpoints anonymously unless explicit authorization token extraction (`supabase.auth.getUser()`) is performed.
**Prevention:** Always authenticate the caller using `supabase.auth.getUser()` in Supabase Edge Functions handling sensitive actions, validate ownership against the database, fetch authoritative amounts server-side, and return generic error messages to avoid information disclosure.
