## 2026-07-12 - [Harden SMS Edge Function Authentication]
**Vulnerability:** The SMS Edge Function (`supabase/functions/sms/index.ts`) was exposed publicly without authentication or validation, allowing anyone to send unauthenticated POST requests and exhaust third-party API credits (Africa's Talking).
**Learning:** By default, Deno-based Supabase Edge Functions do not enforce JWT or token validation unless explicitly implemented in the request handler. Standard client-side invocations via `supabase.functions.invoke()` automatically forward the Authorization header, which the Edge Function must explicitly parse and verify using `supabase.auth.getUser()`.
**Prevention:** Always verify the existence of the `Authorization` header first to avoid runtime `TypeError`s, extract the Bearer token case-insensitively, and validate user authentication securely. Handle errors with standard `try/catch` and return generic client-facing messages to avoid leaking implementation details.
